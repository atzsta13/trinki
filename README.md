# Party Penguin 🐧

Offline party card game for groups: add your friends, pick the vibe and pass the phone. Free forever: no ads, no subscriptions, no accounts.
React web app, shipped to Android and iOS with Capacitor. Two editions: 13+ for the app stores (ice cubes instead of drinks), 18+ for the web.

```bash
npm install
npm run dev     # start locally
npm run check   # lint + tests + both builds
```
